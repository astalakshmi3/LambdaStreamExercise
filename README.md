 ### Lambda and Stream API Examples
This repository contains examples of using Lambda expressions and the Stream API in Java. These examples demonstrate how to leverage functional programming concepts to write more concise and readable code.

## Examples Included
   1. **Lambda Expressions**: Examples of how to use lambda expressions to implement functional interfaces, making code more succinct.
   2. **Stream API**: Examples showcasing the use of the Stream API for processing collections of data in a functional style, including operations like filtering, mapping, and reducing.
   3. **Predicates and Cunsumers**: Demonstrations of using built-in functional interfaces such as Predicate and Consumer to perform operations on data.
   4. **Method References**: Examples of using method references to simplify lambda expressions.
